# MySQL

This is my personal repository where I'm learning **SQL with MySQL**. I made it mainly for myself, but sharing it here in case it helps someone else too.

It's a collection of notes, queries, and examples that I'm using to learn SQL step by step.

## What's inside

* SQL basics
* Creating databases and tables
* `INSERT`, `SELECT`, `UPDATE`, and `DELETE`
* Filtering and sorting data
* Aggregate functions
* `GROUP BY` and `HAVING`
* `JOIN`s
* Subqueries
* Primary and foreign keys
* Constraints
* Views
* Indexes
* Practice queries

(This list matches roughly what's in the repository — I'll update it as I learn more.)

## How to use it

1. Clone the repo:

```bash
git clone https://github.com/zaibgray/sql.git
cd sql
```

2. Make sure MySQL is installed and running.

3. Explore the notes and SQL queries as you learn.

## Why I made this

I wanted a simple place to learn SQL, practice MySQL, and keep everything I've learned in one place.

If it helps you learn too, that's a bonus.
